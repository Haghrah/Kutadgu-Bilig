## Kutadgu Bilig (Digital Text Corpus)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Format: Plain Text](https://img.shields.io/badge/Format-UTF--8-green.svg)]()

A digitized, parallel textual repository of **Kutadgu Bilig**, the 11th-century Karakhanid Turkic masterpiece written by **Yūsuf Khāṣṣ Ḥājib** of Balasagun. 

This repository provides the complete text in both **Latin-based transcription** and **Arabic script**, formatted for computational linguistics, philological analysis, and digital humanities research.
